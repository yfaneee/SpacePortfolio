# SpacePortfolio

# Description
A galaxy/space created by me where you can explore my portfolio and my work. Navigate through an immersive 3D environment to discover projects and documentation for my learning outcomes.

# Table of Contents
Installation

# Installation

Clone the repository:

git clone https://github.com/yourusername/spaceportfolio.git

Open the project directory:

cd spaceportfolio

Run the project on a live server.

# Usage
Simply run the project on a live server and use your mouse and keyboard to navigate through the space. Explore constellations representing different parts of the portfolio, such as projects and learning outcomes.

# Features
User-friendly interface: Navigate seamlessly through the space.

Free navigation: Use your mouse and keyboard to move around like in a game.
