Hike One - Media Campaign

Introduction

For this project, guided by our client Hike One, we were tasked with redesigning the "Calculate Your Premium" health insurance process for a Dutch provider. Out of CZ, Zekur, and another insurer, we chose CZ for its broad user base and potential for improvement. The focus was on creating a more user-friendly and visually cohesive experience while incorporating feedback from user testing to refine the design.

Research Plan

This research explores user-centric interface design principles to create adaptable systems for diverse user groups. Key focuses include customizable settings, error prevention, and simplified navigation to improve accessibility and usability. The plan emphasizes user testing, familiar patterns, and assistive technologies to ensure an inclusive experience for all.

Reflection

This project highlighted the importance of iterative design and user-centered development. By starting with in-depth research and analysis of CZ’s existing interface, we identified key areas for improvement, such as consistency, clarity, and accessibility. The user tests provided actionable insights, revealing both strengths—like the functionality of the menu—and weaknesses, such as visual inconsistencies in layout and button styling. Addressing these challenges not only enhanced the usability of the mobile prototype but also reinforced the value of collaboration and stakeholder feedback in shaping the final product. This experience underscored the necessity of refining designs through testing and maintaining flexibility to adapt to user needs.
